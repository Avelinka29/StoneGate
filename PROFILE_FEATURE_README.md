# Функционал профиля пользователя - Реализация

## Обзор

Была реализована полноценная система профиля пользователя с возможностью просмотра, редактирования данных и управления аватаркой.

## Реализованные возможности

### 1. Просмотр профиля (ProfileView)
- ✅ Загрузка реальных данных пользователя с сервера
- ✅ Отображение аватарки пользователя или placeholder по умолчанию
- ✅ Отображение имени и email
- ✅ Статус верификации (подтверждён/не подтверждён)
- ✅ Кнопка "Редактировать профиль"
- ✅ Переключатели для уведомлений и биометрии с автосохранением

### 2. Редактирование профиля (EditProfileView)
- ✅ Редактирование имени
- ✅ Редактирование email
- ✅ Редактирование телефона
- ✅ Загрузка аватарки через PhotosPicker
- ✅ Удаление аватарки
- ✅ Предпросмотр выбранной аватарки
- ✅ Обработка ошибок с понятными сообщениями
- ✅ Индикатор загрузки

### 3. Бекенд API

#### Обновленные модели
- Добавлено поле `avatar_url` в модель `User`
- Обновлена схема `UserResponse` с полем `avatar_url`
- Создана схема `UserProfileUpdate` для редактирования профиля

#### Новые endpoints

**GET /user/profile**
- Получение профиля текущего пользователя
- Возвращает все данные включая avatar_url

**PATCH /user/profile**
- Обновление профиля (имя, email, телефон)
- Проверка уникальности email при изменении
- Требует авторизацию

**POST /user/avatar**
- Загрузка аватара
- Поддерживаемые форматы: JPEG, PNG, WEBP
- Максимальный размер: 5MB
- Автоматическое удаление старого аватара при загрузке нового
- Сохранение в `/uploads/avatars/`
- Генерация уникального имени файла

**DELETE /user/avatar**
- Удаление аватара пользователя
- Удаление файла с диска
- Обновление базы данных

#### Инфраструктура
- Настроена раздача статических файлов через `/uploads`
- Создана папка `uploads/avatars` для хранения аватаров
- Добавлена миграция базы данных для поля `avatar_url`

## Технические детали

### Безопасность
- Все endpoints требуют JWT авторизацию
- Проверка типа и размера загружаемых файлов
- Проверка уникальности email при изменении
- Автоматическое удаление старых файлов

### База данных
```sql
ALTER TABLE users ADD COLUMN avatar_url VARCHAR;
```

### Структура хранения аватаров
```
backend/
  uploads/
    avatars/
      {uuid}.{extension}
```

### URL структура
- Аватары доступны по адресу: `http://127.0.0.1:8001/uploads/avatars/{filename}`
- Frontend использует относительный путь из `avatar_url`

## Как использовать

### 1. Запуск бекенда
```bash
cd backend
python3 -m uvicorn app:app --reload --host 0.0.0.0 --port 8001
```

### 2. Тестирование API

**Получить профиль:**
```bash
curl -X GET http://127.0.0.1:8001/user/profile \
  -H "Authorization: Bearer {token}"
```

**Обновить профиль:**
```bash
curl -X PATCH http://127.0.0.1:8001/user/profile \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"name":"Новое Имя","phone":"+375291234567"}'
```

**Загрузить аватар:**
```bash
curl -X POST http://127.0.0.1:8001/user/avatar \
  -H "Authorization: Bearer {token}" \
  -F "file=@/path/to/image.jpg"
```

**Удалить аватар:**
```bash
curl -X DELETE http://127.0.0.1:8001/user/avatar \
  -H "Authorization: Bearer {token}"
```

### 3. Использование в iOS приложении

1. Запустите приложение
2. Авторизуйтесь
3. Перейдите в раздел "Профиль"
4. Нажмите "Редактировать профиль"
5. Измените данные или загрузите аватарку
6. Нажмите "Готово"

## Обработка ошибок

### Бекенд
- 400: Неверный тип файла или слишком большой размер
- 400: Email уже зарегистрирован (при изменении)
- 401: Неавторизован
- 404: Аватар не найден (при попытке удалить несуществующий)

### iOS
- Отображение alert с описанием ошибки
- Автоматический сброс состояния при ошибке загрузки
- Индикаторы загрузки для всех операций
